## About the Project

This project demonstrates the use of Git, GitHub, Docker,
and GitHub Actions to build and automate the deployment
of a simple personal portfolio website.

## Technologies Used

- HTML for page structure
- CSS for styling
- Git and GitHub for version control
- Docker with Nginx for containerization
- GitHub Actions for CI/CD automation

## Run Locally

Open `index.html` in a web browser.

## Docker

The website will be served through an Nginx Docker container
on port 8080.

## Required Files

- `index.html`
- `style.css`
- `Dockerfile`
- `.gitignore`
- `.github/workflows/ci.yml`
